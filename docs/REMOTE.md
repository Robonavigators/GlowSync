# Using GlowSync with a TV remote

Use the D-pad to move between controls, Select to activate a focused button, and Back to return from Devices, Calibration or Settings to Home. The setup wizard uses Back to return to the previous step. Focused buttons have a visible border; selection on a narrower display may require scrolling.

Enter a WLED IP address or hostname with the TV's on-screen keyboard. On Home, Start Sync is disabled when the controller address is blank or a capture session is active; the screen explains when an address is missing. In Calibration, select LED counts, offset and direction; use the one-LED marker while sync is stopped to check physical ordering. Sliders adjust the focused value with remote directional input. Save configuration after changes on the main screen; setup calibration changes apply as they are made.

Android's capture permission dialog is provided by the operating system, so its layout and navigation may differ by device and Android version. These controls have been exercised in an emulator; physical remote behavior on individual TVs still needs validation.
