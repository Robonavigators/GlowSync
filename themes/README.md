# Appearance and themes

GlowSync currently has one built-in Compose appearance. It does not load theme files or support user-installable themes. The application's palette and controls live in [MainActivity.kt](../app/src/main/java/com/robonavigators/glowsync/MainActivity.kt). Preserve TV-friendly contrast, remote focus visibility, and reduced-motion behavior when changing them; decorative effects must not interfere with the capture pipeline.
