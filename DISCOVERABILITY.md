# Help GlowSync reach more Android TV and WLED users

GlowSync is already public and MIT-licensed. This page tracks practical outreach that accurately describes the current **early preview**, without claiming physical TV/WLED validation or universal compatibility.

## Share responsibly

- [Project website](https://robonavigators-io.vercel.app/GlowSync/)
- [Source code](https://github.com/Robonavigators/GlowSync)
- [Preview release notes](https://github.com/Robonavigators/GlowSync/releases/tag/v0.1.0-preview.1)
- [Contributing](CONTRIBUTING.md)
- [Troubleshooting](docs/TROUBLESHOOTING.md)

**Short description:** GlowSync is an open-source Android TV / Google TV ambient-lighting app by Robonavigators. It samples permitted on-screen colours locally and streams per-LED RGB data to WLED over the local network. Currently in early preview; physical TV and LED hardware validation is still needed.

## Discoverability checklist

- [ ] Add the short description in **Settings → General → About** on GitHub.
- [ ] Add repository topics: `android-tv`, `google-tv`, `wled`, `ambilight`, `ambient-lighting`, `led-strip`, `android`, `kotlin`, `open-source`, `ddp`.
- [ ] Keep the repository homepage pointed at the project website.
- [ ] Publish a tested, downloadable APK in a release when safe to distribute; the current preview release has no APK asset.
- [ ] Test on actual TV and WLED hardware, document device compatibility, and provide real demonstration photos or a video.
- [ ] Share the real demo and GitHub URL with relevant WLED, Android TV and open-source communities, following their posting rules.
- [ ] Invite actionable bug reports, hardware test results and pull requests via the existing issue/contribution guidance.
- [ ] Consider enabling GitHub Discussions when maintainers can moderate it.
- [ ] Submit the project website for indexing through Google Search Console; ensure it has a useful title, description and canonical URL.

Do not post repeated unsolicited promotion, purchase fake stars, or promise HDMI/DRM capture. Visibility grows best through a reliable demo, useful documentation and genuine community feedback.
