# Security

GlowSync processes screen frames locally and communicates with WLED over unencrypted local HTTP and UDP. Use a trusted network and do not publish captured frames, credentials or private network details when reporting problems.

Please report suspected vulnerabilities privately using GitHub's private vulnerability reporting if it is available for this repository. If it is unavailable, contact the repository owner privately through their GitHub profile before disclosing sensitive details publicly. Avoid filing a public issue containing an exploitable vulnerability or sensitive data.
